# iOS 27 真机回归清单

这份清单用于发布前的稳定性验收。必须使用至少一台 iOS 27 实体 iPhone；模拟器结果不能代替真实配对和定位会话。

## 基础环境

- [ ] 全新安装后，简体中文界面、权限文案和 App 名称显示正常。
- [ ] 拒绝本地网络权限时，错误可理解，且可以前往系统设置恢复。
- [ ] 无 LocalDevVPN 时，App 会引导安装，不会假报连接成功。

## 配对

- [ ] 第一次本机配对可完成，配对记录重启 App 后仍存在。
- [ ] 切换到系统设置完成配对时任务不会中断，也不依赖 `BGTaskScheduler` 注册。
- [ ] PIN 过期、取消、输错时均能重试，不留下卡住的后台任务。
- [ ] 导入错误设备的配对文件时，不会连接到其他设备。
- [ ] 移除配对记录后，旧密钥已从钥匙串清除。

## Wi-Fi 连接

- [ ] LocalDevVPN 已连接时，固定位置可在一次操作内启动。
- [ ] mDNS 识别已配对设备后，定位会话通过 LocalDevVPN 的 `10.7.0.1` 连接，不使用 USB/Wi-Fi 广播的 `169.254.x.x` 链路本地地址。
- [ ] 诊断页只有在 TCP 端口真实可达时才显示通过。
- [ ] 切换 Wi-Fi、锁屏 5 分钟、回到前台后，会话可继续或明确恢复。

## 蜂窝网络（LocalDevVPN）

- [ ] 仅使用 4G/5G 时，引导能正确说明何时暂停、何时恢复蜂窝数据。
- [ ] 建立安全会话后恢复蜂窝数据，定位仍然保持。
- [ ] 启动过程中网络短暂波动时，可以按现有提示重试，不会因为后台任务标识不匹配而阻止会话启动。

## 隧道跳转应用（新分支，待真机）

- [ ] 默认 LocalDevVPN；切换 Shadowrocket、Surge、Loon、Stash、Egern、Quantumult X 或 sing-box 后重启 App 仍保留选择，重置后恢复默认。
- [ ] Wi-Fi 下本次能连接配对设备时不跳转，连接不可用时打开所选应用；蜂窝下 LocalDevVPN 保留原有建立隧道并返回流程，Shadowrocket 通过 `shadowrocket://connect` 开启 VPN，Surge 通过 `surge:///start` 启动当前配置，Loon 通过 `loon://on` 开启 VPN；Stash、Egern 分别通过 `stash://start`、`egern:/start` 启动，Quantumult X 和 sing-box 只打开应用，需手动开启隧道。
- [ ] 连续停止并重新开始模拟定位：Wi-Fi 下本次已断开应重新跳转，本次仍可连通不应重复跳转；蜂窝下 LocalDevVPN 会按原流程打开一次。
- [ ] Shadowrocket、Surge 或 Loon + 蜂窝网络连接失败时，引导改用 Wi-Fi，不显示 LocalDevVPN 的“暂时关闭蜂窝数据”步骤；LocalDevVPN 原蜂窝流程保持不变。
- [ ] 手动开启隧道返回 WrapPin 后继续发现和连接；未安装或不支持跳转链接时显示明确错误及所选应用的商店入口。
- [ ] 固定位置、步行、驾车都经过同一启动检查；Shadowrocket 开启“包含路由 10.7.0.1/32”后可提供配对设备通道并启动定位会话；关闭该开关时不得显示连接成功。
- [ ] Surge iOS 5.23.0+ 按 [Surge iOS 配置](SurgeIntegration.zh-CN.md) 设置后，可提供 `10.7.0.1` 配对设备通道并启动定位会话；缺少 `reflect` 规则或 Surge 版本过旧时，不得显示连接成功。
- [ ] Loon Build 1007+ 按 [Loon 配置](LoonIntegration.zh-CN.md) 设置后，可提供 `10.7.0.1` 配对设备通道并启动定位会话；未启用 `reflect` 插件或 Loon 版本过旧时，不得显示连接成功。
- [ ] 切换 App 或锁屏、蜂窝数据暂关和恢复后，可停止模拟并恢复真实位置。

## 坐标模式记忆

- [ ] 选择收藏或历史地点时沿用该地点上次使用的坐标模式；距上次手动切换 100 公里内的新地点沿用那次的手动选择；重置 WrapPin 后两者都被清除。

## 快捷指令（必须真机验证）

- [ ] 设置 → 快捷指令能打开介绍页，底部按钮跳到“快捷指令”App 的 WrapPin 页面并列出两条快捷指令；SideStore 安装的标准版也要检查。
- [ ] “模拟收藏地点”列出当前收藏，打开 WrapPin 并按记住的坐标模式开始模拟所选地点，App 完全退出时也能正常运行。
- [ ] “停止并恢复真实位置”只在真实位置恢复后报告成功；意外中断后会执行恢复；没有模拟时如实提示。
- [ ] 未完成设置、未配对、收藏已删除、路线模拟进行中、存在待处理的中断记录或另一个定位操作未结束时，提示原因且不做任何改动。

## 定位会话

- [ ] 北京、上海、广州、成都等地点可搜索并启动固定位置。
- [ ] 粘贴中文逗号、带 N/S/E/W 的度数、“北纬/东经”或度分秒格式的坐标，选中的点与十进制写法一致。
- [ ] 未配置 Geoapify Key 时不显示“国内/海外”切换；配置后，海外模式输入时不出现实时建议，只在轻点“搜索”时发出一次请求。
- [ ] 海外候选都显示精度标签，城市级及更粗的结果为橙色；Geoapify 与 OpenStreetMap 署名链接可以打开。
- [ ] 以国家名开头的查询（法国巴黎、美国纽约第五大道350号）只返回该国家的结果；带门牌号的查询中，不在门牌上的结果显示橙色“大致位置”。
- [ ] 选择海外候选后保留其名称和地址，地图居中到该点；在大陆推荐范围以外默认使用 WGS-84。
- [ ] 7 天内重复同一海外搜索不发请求；同一天搜索 50 次后显示次数用完的提示，粘贴坐标仍然可用。
- [ ] Key 无效或被暂停时显示“海外搜索暂时不可用”，而不是空列表。
- [ ] 在中国大陆关闭所有代理（LocalDevVPN 可保持开启）时，海外搜索连不上会提示可开启代理或粘贴坐标；分别记录 Wi-Fi 和蜂窝网络能否直连 Geoapify。
- [ ] 会话中更新位置不需要重新配对或重建隧道。
- [ ] 在地点卡片上向下滑或轻点顶部横条可收起，向上滑或再点一次可展开，重启 App 后保持该状态；从按钮上起滑不会触发该按钮。
- [ ] 卡片收起时，坐标方式小菜单可以切换模式；未配对、连接中、失败、恢复中的状态文案和“停止并恢复”仍然显示。
- [ ] 步行路线的开始、暂停、继续、反向和停止均正常。
- [ ] 步行或驾车预览有多条路线时，卡片最多列出三条；在卡片上选择或轻点地图上的路线后，该路线高亮，距离和用时随之更新；点在所有路线之外仍是地图选点。
- [ ] 开始后地图上只保留所选路线，模拟位置沿该路线移动。
- [ ] 自定义步行速度可按 0.5 公里/小时选择 1–12 公里/小时，预计用时随之更新，切回三档预设正常；异常中断后恢复原速度。
- [ ] 预览驾车路线时使用道路路线；调整 5–240 km/h 模拟速度会更新预计用时，且预览不会启动定位模拟。
- [ ] 驾车模拟在城区、高速和跨城路线可开始、暂停、继续、到达、停止；到达后不会把单行道路线反向复用。
- [ ] 驾车路线中断后保留路线模式与速度并从上次位置恢复；旧版步行中断记录仍可恢复。
- [ ] 驾车模式锁屏、切换 App 后持续推进；停止后在 Apple 地图和另一款 App 中确认真实位置恢复。
- [ ] 首次启动时会请求定位权限，“连接检测”能显示后台保持状态。
- [ ] 拒绝定位权限时，前台模拟仍可启动，并明确提示切换 App 后不保证持续。
- [ ] “减少后台定位指示器”关闭且允许定位权限时，切换 App 或锁屏后会话保持；停止后蓝色后台定位指示器消失。
- [ ] 手动停止或 App 异常退出后，均可恢复真实位置。
- [ ] 在“连接中”阶段点停止，应很快回到就绪状态，且不会短暂写入所选位置。
- [ ] 系统语言为简体中文时，启动失败显示中文提示，连接健康中的会话问题阶段是具体阶段，而不是 `locationUnknown`。
- [ ] 恢复后在 Apple 地图与至少一个第三方 App 中复核真实位置。
- [ ] 停止并恢复后立刻点“当前位置”按钮，地图应回到真实位置，而不是上一个模拟位置。

### 减少后台定位指示器（可选；必须真机验证）

- [ ] 全新安装默认关闭，沿用原有“使用 App 期间”申请与指示器行为；已授予“始终”权限时，开关关闭仍显示指示器。
- [ ] 尚未授权时主动开启，先申请“使用 App 期间”，获得后再申请升级为“始终”。另测“允许一次”：升级不可用时，说明与“打开系统设置”入口仍可用。
- [ ] 已有“使用 App 期间”权限时，仅主动开启会申请“始终”。保留开启状态后重启、开始会话或回到前台，均不再次申请升级。
- [ ] 拒绝“始终”升级，或系统已不再弹出升级提示：开关保持开启，指示器仍显示，并有说明与系统设置入口。
- [ ] 在系统设置中授予“始终”后返回，“连接检测”显示新的授权级别与“运行时隐藏”；降级为“使用 App 期间”后返回，显示“运行时显示”，不再次申请升级。
- [ ] iOS 27 上开关开启且已获“始终”权限时，实际观察模拟期间蓝色灵动岛指示器是否消失。诊断值只表示请求的显示方式，不证明系统界面的实际效果。
- [ ] 会话运行中开关切换立即更新指示器行为，不重启模拟；关闭不会撤回“始终”权限，可在系统设置中改回“使用 App 期间”。
- [ ] 对照开关开启与关闭，在固定位置、步行、驾车模式下检查锁屏与长时间后台保持；隐藏指示器不能让保持变差，两种状态均验证短暂断线后的有限重连。
- [ ] 两种开关状态下，“停止模拟并恢复”均结束定位更新，指示器消失；在 Apple 地图与另一款 App 中确认真实位置恢复。
- [ ] 文案说明 iOS 可能定期提醒后台使用位置，后台保持坐标不保存、不上传；未新增统计事件或位置字段。

## 异常中断与恢复

- [ ] 固定位置、步行、驾车模拟中途短暂中断设备连接：以 1、2、4 秒间隔最多连续重连 3 次，期间保持保活请求；成功后沿用原坐标模式与最新位置，路线不计入断线期间的行进时间，用户暂停状态保留。
- [ ] 连接持续不可用，或配对认证失败：重连耗尽或遇不可重试错误后显示恢复入口，重启后仍保留最新路线位置、坐标方式和速度。确认未在超时的旧通道上继续读写。
- [ ] 在重连等待和连接阶段分别点停止、重置；等待超过原重连延迟后，模拟不会重新启动。未确认清除时仍保留恢复入口；主动恢复真实位置的流程不自动恢复模拟。
- [ ] 点击启动后立即切到其他 App 或锁屏：前台已建立保活请求；若首次保活尚未能在前台启动，诊断不得假报已启动，返回后可重新建立。停止启动和配对读取失败均释放保活。
- [ ] 标准版与隧道版分别覆盖前台、后台、锁屏 5/30/60 分钟和网络切换；复制诊断可见最近保活回调时间、是否正在重连及重连次数。编译和替身测试不能替代这些真机项目。
- [ ] 隧道不可用时重试恢复，以及改选新地点后连接失败：已有未确认记录和恢复入口仍然存在。
- [ ] 设备无响应时，在 WrapPin 能正常执行的前提下，坐标写入和清除各在 15 秒后超时，停止不会无限等待；写入接近超时时成功后再发生清除超时，整体可能接近 30 秒。
- [ ] 停止未获清除确认时出现恢复入口；重连设备隧道后，分别验收“继续模拟”和“恢复真实位置”，在 Apple 地图及另一款 App 中确认结果。
- [ ] 已有恢复记录时，在首次写入前取消新启动：旧记录仍保留；确认清除、新会话进入运行状态或主动忽略后，记录才删除或替换。
- [ ] 会话运行期间拒绝定位权限，回到首页可见后台保持警告；重新允许后回前台，保活可对账恢复，模拟会话不自动重连。
- [ ] 从多任务界面划掉 App 会结束模拟连接，VPN 仍连接不能作为模拟持续生效的依据。

## 诊断与隐私

- [ ] 失败后可看到连接阶段、最后一条完整错误和明确的下一步操作。
- [ ] 诊断报告不包含配对记录、密钥、PIN、设备名称或实际 IP。
- [ ] 匿名使用统计保持默认关闭。
