# iOS 27 真机回归清单

这份清单用于发布前的稳定性验收。必须使用至少一台 iOS 27 实体 iPhone；模拟器结果不能代替真实配对和定位会话。

## 基础环境

- [ ] 全新安装后，简体中文界面、权限文案和 App 名称显示正常。
- [ ] 拒绝本地网络权限时，错误可理解，且可以前往系统设置恢复。
- [ ] 无 LocalDevVPN 时，App 会引导安装，不会假报连接成功。

## 配对

- [ ] 第一次本机配对可完成，配对记录重启 App 后仍存在。
- [ ] 切换到系统设置完成配对时任务不会中断，也不依赖 `BGTaskScheduler` 注册。
- [ ] PIN 过期、取消、输错时均能重试，不留下卡住的后台任务。
- [ ] 导入错误设备的配对文件时，不会连接到其他设备。
- [ ] 移除配对记录后，旧密钥已从钥匙串清除。

## Wi-Fi 连接

- [ ] LocalDevVPN 已连接时，固定位置可在一次操作内启动。
- [ ] mDNS 识别已配对设备后，定位会话通过 LocalDevVPN 的 `10.7.0.1` 连接，不使用 USB/Wi-Fi 广播的 `169.254.x.x` 链路本地地址。
- [ ] 诊断页只有在 TCP 端口真实可达时才显示通过。
- [ ] 切换 Wi-Fi、锁屏 5 分钟、回到前台后，会话可继续或明确恢复。

## 蜂窝网络（LocalDevVPN）

- [ ] 仅使用 4G/5G 时，引导能正确说明何时暂停、何时恢复蜂窝数据。
- [ ] 建立安全会话后恢复蜂窝数据，定位仍然保持。
- [ ] 启动过程中网络短暂波动时，可以按现有提示重试，不会因为后台任务标识不匹配而阻止会话启动。

## 隧道跳转应用（新分支，待真机）

- [ ] 默认 LocalDevVPN；切换 Shadowrocket、Surge 或 Loon 后重启 App 仍保留选择，重置后恢复默认。
- [ ] Wi-Fi 下本次能连接配对设备时不跳转，连接不可用时打开所选应用；蜂窝下 LocalDevVPN 保留原有建立隧道并返回流程，Shadowrocket 通过 `shadowrocket://connect` 开启 VPN，Surge 通过 `surge:///start` 启动当前配置，Loon 通过 `loon://on` 开启 VPN。
- [ ] 连续停止并重新开始模拟定位：Wi-Fi 下本次已断开应重新跳转，本次仍可连通不应重复跳转；蜂窝下 LocalDevVPN 会按原流程打开一次。
- [ ] Shadowrocket、Surge 或 Loon + 蜂窝网络连接失败时，引导改用 Wi-Fi，不显示 LocalDevVPN 的“暂时关闭蜂窝数据”步骤；LocalDevVPN 原蜂窝流程保持不变。
- [ ] 手动开启隧道返回 WrapPin 后继续发现和连接；未安装或不支持跳转链接时显示明确错误及所选应用的商店入口。
- [ ] 固定位置、步行、驾车都经过同一启动检查；Shadowrocket 开启“包含路由 10.7.0.1/32”后可提供配对设备通道并启动定位会话；关闭该开关时不得显示连接成功。
- [ ] Surge iOS 5.23.0+ 按 [Surge iOS 配置](SurgeIntegration.zh-CN.md) 设置后，可提供 `10.7.0.1` 配对设备通道并启动定位会话；缺少 `reflect` 规则或 Surge 版本过旧时，不得显示连接成功。
- [ ] Loon Build 1007+ 按 [Loon 配置](LoonIntegration.zh-CN.md) 设置后，可提供 `10.7.0.1` 配对设备通道并启动定位会话；未启用 `reflect` 插件或 Loon 版本过旧时，不得显示连接成功。
- [ ] 切换 App 或锁屏、蜂窝数据暂关和恢复后，可停止模拟并恢复真实位置。

## 定位会话

- [ ] 北京、上海、广州、成都等地点可搜索并启动固定位置。
- [ ] 会话中更新位置不需要重新配对或重建隧道。
- [ ] 步行路线的开始、暂停、继续、反向和停止均正常。
- [ ] 步行或驾车预览有多条路线时，卡片最多列出三条；在卡片上选择或轻点地图上的路线后，该路线高亮，距离和用时随之更新；点在所有路线之外仍是地图选点。
- [ ] 开始后地图上只保留所选路线，模拟位置沿该路线移动。
- [ ] 自定义步行速度可按 0.5 公里/小时选择 1–12 公里/小时，预计用时随之更新，切回三档预设正常；异常中断后恢复原速度。
- [ ] 预览驾车路线时使用道路路线；调整 5–240 km/h 模拟速度会更新预计用时，且预览不会启动定位模拟。
- [ ] 驾车模拟在城区、高速和跨城路线可开始、暂停、继续、到达、停止；到达后不会把单行道路线反向复用。
- [ ] 驾车路线中断后保留路线模式与速度并从上次位置恢复；旧版步行中断记录仍可恢复。
- [ ] 驾车模式锁屏、切换 App 后持续推进；停止后在 Apple 地图和另一款 App 中确认真实位置恢复。
- [ ] 首次启动时会请求定位权限，“连接检测”能显示后台保持状态。
- [ ] 拒绝定位权限时，前台模拟仍可启动，并明确提示切换 App 后不保证持续。
- [ ] 允许定位权限后，切换 App 或锁屏时会话保持；停止后蓝色后台定位指示器消失。
- [ ] 手动停止或 App 异常退出后，均可恢复真实位置。
- [ ] 在“连接中”阶段点停止，应很快回到就绪状态，且不会短暂写入所选位置。
- [ ] 系统语言为简体中文时，启动失败显示中文提示，连接健康中的会话问题阶段是具体阶段，而不是 `locationUnknown`。
- [ ] 恢复后在 Apple 地图与至少一个第三方 App 中复核真实位置。
- [ ] 停止并恢复后立刻点“当前位置”按钮，地图应回到真实位置，而不是上一个模拟位置。

## 诊断与隐私

- [ ] 失败后可看到连接阶段、最后一条完整错误和明确的下一步操作。
- [ ] 诊断报告不包含配对记录、密钥、PIN、设备名称或实际 IP。
- [ ] 匿名使用统计保持默认关闭。
