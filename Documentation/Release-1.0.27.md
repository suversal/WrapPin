# WrapPin 1.0.27 (Build 106)

[简体中文](Release-1.0.27.zh-CN.md)

- Save custom routes for reuse, rename or delete them in Saved Places, and reload their waypoints, coordinate mode and speed in one tap.
- Show recent searches below the map search bar so recently used places can be picked again quickly without retyping.
- Refine the interface with iOS 26+ Liquid Glass styling, improved bottom-dock drag physics, and cleaner map overlays and interaction transitions across the home map, route editors and precision picker.

Both IPAs are unsigned and require iOS/iPadOS 18.0 or later. Use Standard for SideStore. Tunnel requires matching Packet Tunnel signing profiles for the app and its embedded extension. Upgrade the same edition with the existing signing identity. [Installation guide](Installation.md)
