# iPad 地图面板：Build 71

最低系统仍为 iOS/iPadOS 18.0。标准版与隧道版使用同一套布局，配对和定位引擎未修改。Build 70 的包与记录保留；Build 71 打包待完成。

## 操作方式

- **横向宽窗口**：窗口宽度至少 900 pt 且宽大于高时使用左侧操作区。点击顶部“收起控制面板”或向左滑动标题区可以隐藏；地图铺满后，左上角“显示控制面板”可恢复。
- **隐藏侧栏时**：已有选点／路线会保留底部紧凑卡片。固定定位保留状态和“停止模拟并恢复”；路线保留暂停／继续及停止。点击“展开详情”恢复侧栏并展开对应详情，不会取消当前选点或会话。
- **竖向和窄窗口**：搜索与快捷入口在顶部，操作卡片明确贴在底部安全区上方，内容最大宽度 420 pt。按内容高度布局，展开内容过高时才在卡片内滚动；上方工具和下方卡片互相避让。
- **详情收起／展开**：固定定位和路线都显示可点击的文字入口，也可在卡片顶部上下拖动。手势不覆盖卡片主体，避免拦截滚动、坐标选择和速度调节。
- **偏好**：iPad 首次使用新版默认紧凑显示；旧版 iPhone 的收起偏好会保留。展开状态在选点、路线、旋转之间共享；侧栏隐藏偏好单独保存。
- **地图消息**：提示条按当前卡片高度和侧栏位置避让，避免覆盖停止按钮。

隐藏面板只改变界面，不会停止定位、清除选点或重新配对。停止仍走原来的确认与恢复流程。

## 验证与边界

正常字号下，iPad mini 的竖屏贴底、双向横屏、侧栏隐藏与恢复、旋转后选点保留、固定／路线的详情展开收起以及停止确认入口均已通过 UI 检查；375 pt iPhone 的固定／路线卡片交互也通过。两台设备的最大辅助字号、深色模式检查也通过，并覆盖“减少动态效果”的渲染分支。大字体下，卡片可滚动，部分操作需要滚动后显示。

这些 UI 检查使用临时工程中的合成定位中／路线状态，不连接真实定位服务；测试数据、放宽的模型 setter 和状态注入均不进入正式源码。正式工程保持最低 iOS 18 的编译检查。

2026-11-07 用户已反馈 iPad iOS 26 可以定位并横屏，截图用于确认本次布局问题；具体构建号、版本类别和完整功能未单独验收。Build 71 真机定位、路线、后台和恢复，iOS 18 真机，以及实际分屏拖动缩放仍待回归。
