# WrapPin 1.0.25（Build 92）

[English](Release-1.0.25.md)

优化自定义路线的地点搜索：

- 国内地点输入和点击“搜索”统一使用联想候选。点击“搜索”收起键盘并保留当前候选，不再换成另一批关键词搜索结果。候选数量由地图服务决定，最多显示六条。
- 点击具体地点建议后直接加入路线并返回，不再要求重复选择；联想结果与搜索结果统一显示添加图标。
- 使用被选建议的精确解析请求；防止取消、过期请求或重复点击错误添加地点。
- 坐标输入和海外搜索保留原有方式，首页搜索行为保持不变。

两版均为 iOS/iPadOS 18.0+ 未签名 IPA。SideStore 使用 Standard，Tunnel 需要匹配的 Packet Tunnel 签名权限。沿用原签名身份升级同一版本类型即可。

验证：路线选点、提交保留六条候选、坐标输入、解析失败、取消与过期请求、恢复和定位连续性回归通过。两版 Release 归档与 IPA 校验通过。模拟器界面检查使用六条注入候选与本地解析样本，不代表地图服务在所有地区均返回六条。真实服务结果与签名后安装仍需手机验收。
