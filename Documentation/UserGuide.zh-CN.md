# WrapPin 使用手册

WrapPin 可以让 iPhone 暂时报告一个固定位置，或沿 Apple 地图规划的步行、驾车路线移动。请只在你拥有并控制的设备上用于开发和测试。

[返回中文首页](../README.md) · [English](UserGuide.md)

Build 70 的 iPad 横屏和窗口宽度适配见 [iPad 布局说明](iPadLayout.zh-CN.md)。真机配对与定位尚待验收。

## 首次设置

iOS 18–26 请先按[电脑配对说明](iOS26Pairing.zh-CN.md)生成并导入 RPPairing 文件。下面的六位码配对步骤适用于 iOS 27 或更高版本。标准版连接外部设备隧道；隧道版允许添加内置 VPN 配置。

开始前需要实体 iPhone 和开发者模式。标准版另需 LocalDevVPN 等设备隧道；隧道版使用内置隧道。

1. 打开 WrapPin，完成三页首次使用说明。
2. 在“设备连接”页面轻点“配对本机”。
3. iOS 询问时，允许本地网络权限。
4. 打开“设置 → 隐私与安全性 → 开发者模式 → 与 WrapPin 配对”。
5. 输入 WrapPin 显示的六位数配对码。
6. 标准版安装 LocalDevVPN 并连接本地隧道；隧道版在开始定位时按提示允许添加内置 VPN 配置。

一般只需配对一次。配对记录保存在本机钥匙串中，不会上传。

## 选择位置

你可以搜索地点、输入经纬度、轻点地图放置位置点，或从“收藏与历史”中选择。经纬度除了 `51.50740, -0.12780`，也可以直接粘贴 `35.6586° N, 139.7454° E`、`北纬35.6586°，东经139.7454°` 或度分秒格式。

国内 iPhone 上的 Apple 地图数据通常没有海外地点。如果你的版本带有海外搜索，轻点搜索框末尾的“国内”切换为“海外”，输入地点后轻点“搜索”。查询以国家名开头（如“法国巴黎”“日本东京塔”）时，只在该国家内查找。结果最多显示 5 个候选，每个都标注精度（门牌、地点、街道、区域、城市等）；橙色标签表示只找到大致位置，请核对后再模拟。查询里带门牌号时，只有落在门牌上的结果才显示为精确。海外搜索需要连接 Geoapify 位于境外的服务器，在中国大陆不开代理可能无法使用，此时可以直接粘贴坐标。海外结果来自 Geoapify，数据来源是 OpenStreetMap，很多门牌地址查不到，日本尤其明显。每台 iPhone 每天可进行 50 次海外搜索，近期重复搜索会直接使用保存的结果。搜不到时，可以直接粘贴该地点的坐标。

选择搜索结果后，搜索框会自动清空；地点卡片上的关闭按钮会取消当前选择。

想多看一些地图时，在地点卡片上向下滑，或轻点卡片顶部的横条即可收起；向上滑或再点一次横条可展开，WrapPin 会记住这个选择。收起后，模拟坐标方式显示为地址旁的小菜单，预览路线和复制坐标按钮暂时隐藏。

## 模拟固定位置

1. 选择地点。
2. 在地点卡片上选择 GCJ-02 修正或 WGS84 原值。国内地点建议先试 GCJ-02，其他地点建议先试 WGS84；这只是初始建议。
3. 轻点“开始模拟定位”。如果出现 LocalDevVPN 或蜂窝网络提示，按页面说明操作。
4. 等待连接状态显示“模拟定位中”，再用 Apple 地图核对显示位置。如果有偏差，可返回 WrapPin 切换另一种模式；同一地点的模拟坐标会随之更新。

需要更换位置时，选择另一个地点并轻点“更换模拟位置”，无需重新建立整条连接。

结束后轻点“停止模拟并恢复”，确认并保持 WrapPin 在前台，直到真实位置恢复。不要在尚未恢复时使用导航、出行、紧急求助或位置共享类 App。

## Wi-Fi 与蜂窝网络

“隧道跳转应用”用于选择 WrapPin 自动打开哪个应用，列表不代表全部兼容软件。其他代理或 VPN 软件只要已正确配置兼容的设备隧道，也可手动开启后返回 WrapPin 使用。能否使用取决于是否能连接已配对 iPhone 的设备通道，而不是软件是否出现在列表中。

可在“设置 → 隧道跳转应用”选择 LocalDevVPN（默认）、Shadowrocket、Surge、Loon、Stash、Egern、Quantumult X 或 sing-box。使用 Wi-Fi 时，WrapPin 会检查已配对 iPhone 的设备连接：能连通就不跳转，无法连通才打开所选应用。蜂窝网络下，LocalDevVPN 保留原有的建立隧道并返回流程，因此启动时仍会打开一次；其他应用则先检查设备连接，连不上时才打开应用；有开启链接的应用会同时请求开启 VPN。WrapPin 不能直接读取这些应用的 VPN 开关状态。

选择 Shadowrocket 时，WrapPin 通过 `shadowrocket://connect` 请求它开启 VPN，之后需要手动返回 WrapPin。Shadowrocket 需要按 [Shadowrocket 配置](ShadowrocketIntegration.zh-CN.md) 在“设置 → 其它”中开启“包含路由 10.7.0.1/32”，才能提供设备连接。蜂窝网络下无法连接时，请改用 Wi-Fi；若 Wi-Fi 下也无法通过连接检测，建议保持默认 LocalDevVPN。

选择 Surge 时，WrapPin 通过 `surge:///start` 请求 Surge 启动当前配置，之后需要手动返回 WrapPin。Surge 需要 iOS 版 5.23.0 或更高版本，并按 [Surge iOS 配置](SurgeIntegration.zh-CN.md) 加入路由和 IP Rewrite 设置，才能提供设备连接。蜂窝网络下无法连接时，请改用 Wi-Fi。

选择 Loon 时，WrapPin 通过 `loon://on` 请求 Loon 开启 VPN，之后需要手动返回 WrapPin。Loon 需要 Build 1007 或更高版本，并按 [Loon 配置](LoonIntegration.zh-CN.md) 加入 `include-tun` 和 IP Rewrite 设置，才能提供设备连接。蜂窝网络下无法连接时，请改用 Wi-Fi。

选择 Stash 或 Egern 时，WrapPin 分别通过 `stash://start`、`egern:/start` 请求开启 VPN，之后需要手动返回 WrapPin。选择 Quantumult X 或 sing-box 时，它们没有开启 VPN 的链接，WrapPin 只会打开应用，请手动开启后返回。这四个应用都需要在各自配置中把发往 `10.7.0.1` 的连接回送到本机，例如 sing-box 1.12 及以上版本需要在 TUN 入站中设置 `loopback_address: 10.7.0.1`；配置后可在“设置 → 连接检测”中确认设备连接是否可用。

使用 Wi-Fi 时，请确认所选应用的兼容设备隧道已连接。默认使用 LocalDevVPN 时，如果仍然找不到本机，先关闭再开启一次隧道，然后轻点“重试”。连接 Wi-Fi 时不要误选“我正在使用蜂窝网络”。

使用 LocalDevVPN 且仅使用 4G/5G 时：

1. 启动所选位置。
2. 页面提示后，暂时关闭蜂窝网络。
3. 回到 WrapPin，等待它自动发现本机；必要时轻点“继续”。
4. 安全连接建立后，按提示重新开启蜂窝网络。

临时关闭蜂窝网络只用于 LocalDevVPN 建立连接。模拟定位开始后，可以恢复正常使用移动数据。LocalDevVPN 以外的应用不使用这套临时关闭蜂窝数据的引导；如果它们在蜂窝网络下无法连接，请切换到 Wi-Fi 后重试。

## 模拟步行路线

1. 选择目的地，轻点“预览步行”。
2. 检查路线、距离、预计用时和到达时间。Apple 地图给出多条路线时，卡片上最多列出三条，可在卡片上选择，或直接轻点地图上的路线。
3. 选择原有的三档步行速度，或打开“自定义步行速度”，以 0.5 公里/小时为单位设置 1–12 公里/小时，再轻点“开始模拟步行”。骑行或更快的行进可按适用路线选择驾车模式。

步行期间可以暂停、继续，也可以切换到其他 App。到达后可以沿原路线返回，或保留当前连接并选择新的目的地。结束时请使用“停止模拟并恢复”。

## 模拟驾车路线

选择目的地后轻点“预览驾车”，先确认 Apple 地图返回的道路路线。在预览中设置 5–240 公里/小时的模拟速度，确认按此速度计算的预计用时，再轻点“开始模拟驾车”。模拟以固定速度沿路线移动，不会根据限速、红绿灯或路况自动减速。行进中可以暂停、继续；结束时使用“停止模拟并恢复”并确认真实位置恢复。

首次启动定位会话时，请允许 WrapPin 使用定位服务。该权限只用于在切换到其他 App 后保持当前会话，坐标仍由系统开发者模拟服务写入，后台保持模块不会保存、比较或上传坐标。模拟期间系统可能显示蓝色后台定位指示器；可在“设置 → 连接检测 → 后台保持”查看状态。若拒绝权限，前台模拟仍可运行，但切换 App 后不保证持续。当前会话已启动但后台保持不可用时，首页也会显示提示。回到前台会重新检查定位权限和保活状态，不会自动重连模拟会话；Core Location 的暂时错误不会直接停止定位更新。

从多任务界面上滑划掉 WrapPin 会结束模拟连接。VPN 仍显示已连接，不代表模拟仍有效；关闭 App 也不代表其他 App 已重新获取真实位置。需要时重新打开 WrapPin，使用恢复入口。

原生引擎通过后续坐标写入发现失联，通常每四秒刷新一次。刷新间隔和 15 秒写入超时都以进程能够执行为前提，不保证系统挂起 App 时仍在 20 秒内发现断连。

### 减少后台定位指示器（可选）

“设置 → 后台定位指示器 → 减少后台定位指示器”默认关闭。保持关闭时，沿用原有“使用 App 期间”的权限申请与指示器行为。主动打开开关后需要“始终”定位权限；尚未授权时，先申请“使用 App 期间”，获得后再申请升级。如果之前拒绝过升级、选择了“允许一次”，或系统未弹出升级提示，请轻点“打开系统设置”，选择“始终”。即使没有获得权限，开关仍保留你的选择；重启 WrapPin、开始模拟或回到前台，都不会自动申请升级。

仅当开关开启且已有“始终”权限时，WrapPin 才请求隐藏蓝色指示器。“设置 → 连接检测 → 后台保持”会显示实际授权级别与请求的指示器显示方式。会话运行中切换开关立即生效，权限降级后恢复显示。最终显示由 iOS 决定；iOS 27 灵动岛、锁屏和长时间后台保持的效果仍需真机验证。本功能不修复设备连接中断。

iOS 可能定期提醒 WrapPin 在后台使用位置。后台保持收到的坐标仍不会保存或上传。关闭开关仅恢复指示器显示，无法撤回“始终”权限；需要时请在系统设置中改回“使用 App 期间”。“停止模拟并恢复”仍会停止定位更新。

## 上次任务意外中断

坐标写入或停止未获设备确认时，本次运行内即可显示恢复页面；保存了未确认记录的情况下，重新打开 App 也会显示。页面上的位置是上次设置的位置，不代表当前仍在生效：

- “继续模拟定位”会重新连接上次的固定位置。
- “继续模拟步行”会按原速度从最近保存的位置准备剩余路线。
- “继续模拟驾车”会按原速度从最近保存的位置重新规划驾车路线。
- “恢复真实位置”只会短暂重连并清除模拟位置。
- “真实位置已经恢复”会清除本次恢复提示，不再连接。

恢复页面不会自动启动任何任务。恢复重试失败，包括改选新地点后连接失败，都保留已有未确认记录。只有设备确认清除成功、新会话开始运行后用新记录覆盖，或用户主动忽略时，才删除或替换旧记录。异常中断会立即保存内存中的最新路线进度，不等待平时的保存间隔。

坐标写入和清除位置各有 15 秒超时。写入超时后直接结束本次操作，不再使用同一条已不可信的连接清除位置。如果写入接近超时时成功，接着清除位置又超时，在 App 能正常运行时，整个停止过程可能接近 30 秒。报错或超时不代表真实位置已经恢复，请在恢复操作后实际核对。

## 快捷指令

WrapPin 会在“快捷指令”App 中自动提供两条现成的快捷指令，无需另外安装。打开“设置 → 快捷指令”可查看说明，并直接跳转到“快捷指令”App 中的 WrapPin 页面。

- **模拟收藏地点**：运行时选择一个收藏地点，WrapPin 会打开并开始模拟该地点，坐标模式沿用这个地点上次的选择。快捷指令只负责发起，连接进度请在 WrapPin 中查看。
- **停止并恢复真实位置**：停止正在进行的模拟；如果上次模拟意外中断，则执行“恢复真实位置”。会等待设备确认后再告知结果。

使用前需要完成配对，并至少收藏一个地点。运行快捷指令时 WrapPin 会切到前台，设备连接不可用时还可能打开所选的隧道应用。如果有模拟意外中断，“模拟收藏地点”会提示先在 WrapPin 中选择恢复或继续，不会自动处理；正在进行路线模拟时，也需要先在 WrapPin 中停止。

可以在“快捷指令 → 自动化”中新建“到达”“离开”或“特定时间”等个人自动化，再添加 WrapPin 的操作。也可以对 Siri 说“用 WrapPin 模拟收藏地点”或“用 WrapPin 恢复真实位置”；隧道版请把 App 名称换成 WrapPin Tunnel。

## 收藏、历史与重置

- 收藏会保留到你手动删除或重置 App。
- 历史记录保存最近使用的 30 个位置。
- “重新查看介绍”不会删除任何数据。
- “重置 WrapPin”会删除配对、收藏、历史记录和本地偏好，但不会卸载或修改 LocalDevVPN。

## 连接排查

如果 LocalDevVPN 已连接但仍找不到本机，先确认当前使用的是 Wi-Fi 还是蜂窝网络，再按对应流程重试。如果提示设备与配对记录不符，请重新打开 LocalDevVPN；仍未解决时，确认记录属于这台 iPhone。iOS 18–26 按[电脑配对说明](iOS26Pairing.zh-CN.md)重新生成、验证并导入记录，iOS 27 可重新配对本机。

“已保存的配对已失效”也可能来自其他配对校验错误，单凭提示不能确认记录过期；请先复制下面的诊断信息。

需要提交问题时，打开“设置 → 连接检测”，运行检查并复制诊断信息。报告中不要附带配对文件、PIN、账号凭据或私人位置。

## 匿名使用统计

匿名统计默认关闭，只有你主动开启后才会发送少量固定的使用计数。它不会发送坐标、地点、搜索、收藏、路线、配对记录、PIN、设备名称或错误原文。你可以随时在“设置 → 隐私”中关闭。完整说明见 [隐私说明](Privacy.zh-CN.md)。
