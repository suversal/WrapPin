# WrapPin 1.0.26 (Build 96)

[简体中文](Release-1.0.26.zh-CN.md)

- The map shows the active fixed simulation target separately from the selected pin. Use **Show simulated target** to center the map on it. [#57](https://github.com/suversal/WrapPin/issues/57)
- Open **Precision Selection**, then drag the map or use the joystick to line up a destination under the fixed crosshair. Tap **Confirm selection** to select the point and **Start Location** or **Update Location** to apply it. [#58](https://github.com/suversal/WrapPin/issues/58) · [#59](https://github.com/suversal/WrapPin/issues/59)
- Keep the selected place title and actions visible above the scrolling map card details.
- Rename a favourite using the pencil button in Saved Places. Renaming keeps the original coordinates, address and position in the list. Address refreshes preserve the custom name. [#61](https://github.com/suversal/WrapPin/issues/61)

Both IPAs are unsigned and require iOS/iPadOS 18.0 or later. Use Standard for SideStore. Tunnel requires matching Packet Tunnel signing profiles for the app and its embedded extension. Upgrade the same edition with the existing signing identity. [Installation guide](Installation.md)
