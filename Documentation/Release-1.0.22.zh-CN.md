# WrapPin 1.0.22（Build 74）

本次优化定位维持和连接中断后的恢复。

- 在前台开始定位时提前启动后台保活；回到前台后，重新检查长时间没有定位回调的保活请求。
- 已开始运行的定位会话遇到可重试的连接错误时，以 1、2、4 秒间隔最多连续重连三次，重新建立连接并沿用最新坐标。稳定运行一分钟后重置重试额度。
- 重连期间暂停路线推进，恢复后继续当前位置，并保留用户的暂停状态。
- 主动停止、重置和恢复真实位置会取消自动重连；配对认证错误和上次启动留下的未确认会话仍需手动处理。
- 连接诊断新增保活最近回调时间、重连状态和尝试次数。

## 下载与安装

[下载 v1.0.22](https://github.com/suversal/WrapPin/releases/tag/v1.0.22)。两版均为未签名 IPA，支持 iOS/iPadOS 18.0 及以上：

- **Standard 标准版**：供 SideStore 等自签方式安装，需要 LocalDevVPN 等外部设备隧道。
- **Tunnel 隧道版**：内置设备隧道，主 App 和扩展需要匹配的 Packet Tunnel 签名权限，免费账号请选择标准版。

沿用同一版本及原签名身份升级，通常无需重新配对。iOS 18–26 的电脑配对方式、iOS 27 的本机 PIN 配对方式不变。
