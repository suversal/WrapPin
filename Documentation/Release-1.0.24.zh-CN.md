# WrapPin 1.0.24（Build 88）

[English](Release-1.0.24.md)

新增自定义路线，在 Apple 地图不提供步行规划的地区也能模拟移动。

- 搜索地点、输入坐标或在地图上点选起点、终点和途经点；途经点插入终点前，支持长按手柄排序、逐个删除、清空确认及撤销。
- 支持导入 GPX 轨迹或路线，多个轨迹段可分别选择。文件上限 5 MB、10,000 个点。
- 统一使用路线模拟，速度滑块支持 0.1–240 公里/小时，步长 0.1；可启动、暂停、继续、返程、停止并恢复真实位置。
- 自定义路线按地点顺序直线连接，不依赖 Apple 步行规划，也不会自动贴合道路；需要沿道路移动时请添加途经点或导入相应 GPX。
- 路线几何计算、GPX 解析和中断记录均在本机完成，不会上传整条自定义路线。地图显示与地点搜索仍可能需要网络，并使用原有地图服务。
- 首页及路线页浮框支持拖动收起、半展开和展开，改善背景可读性、按钮边界和摘要信息；未选地点时显示紧凑提示。
- 移除浮框弹簧吸附；路线页支持回到当前位置，首次打开优先使用可信真实定位或首页地图视野。

## 安装

Standard 标准版适合 SideStore 等自签，需配合外部设备隧道；免费账号请选择标准版。Tunnel 隧道版内置设备隧道，需要匹配的 Packet Tunnel 签名权限。

两版均为 iOS/iPadOS 18.0+ 未签名 IPA。沿用原签名身份覆盖升级同一版本类型，正常配对无需移除。

## 验证范围

路线几何、GPX、速度范围、移动、暂停、重连、停止、到达、返程、选点搜索和恢复记录检查通过；复验定位连续性、本地化及两版 Release 归档与包体。此前已在 iOS 26 模拟器检查浮框反复拖动、统一速度界面及缓存定位居中。UI 测试使用合成状态和公开坐标，没有启动真实设备传输；iOS 18 交互、本次正式包签名安装和长时间后台运行仍待真机验收。
