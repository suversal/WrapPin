# WrapPin 1.0.26（Build 96）

[English](Release-1.0.26.md)

- 固定模拟时，首页单独标出当前模拟目标。查看或点选其他地点时，可以用“查看模拟位置”回到当前目标。[#57](https://github.com/suversal/WrapPin/issues/57)
- 地图新增“精确选点”。拖动地图或用摇杆微调，让目标对准固定准星，再点“确认选点”。点“开始模拟定位”或“更换模拟位置”后才会把选点用于设备会话。[#58](https://github.com/suversal/WrapPin/issues/58) · [#59](https://github.com/suversal/WrapPin/issues/59)
- 修复选点面板滚动后裁切地点标题和按钮的问题。地点摘要固定在面板上方，选项较多时可以滚动。
- “收藏与历史”里，每条收藏旁都有铅笔按钮。改名后保留原坐标、地址和排序，地址刷新会保留手动名称。[#61](https://github.com/suversal/WrapPin/issues/61)

两版均为 iOS/iPadOS 18.0+ 未签名 IPA。使用 SideStore 请选择 Standard。Tunnel 的主 App 和内置扩展都需要匹配的 Packet Tunnel 签名配置。覆盖升级时沿用原版本类型和签名身份。[安装说明](Installation.zh-CN.md)
