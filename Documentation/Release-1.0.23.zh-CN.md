# WrapPin 1.0.23（Build 75）

[English](Release-1.0.23.md)

本版优化本机配对和重新配对的恢复流程。

- 每次新配对生成随机主机标识，与新密钥保持一致。普通启动和定位重连继续使用已保存的成功配对。
- 配对广播端口明确支持 IPv4 与 IPv6 接入。
- 重置先等待旧配对、生成/导入记录写入和定位停止完成，再删除并确认 App 自己的钥匙串记录；旧读取或回调不会把界面改回已配对。定位停止仍走原有恢复与确认流程。
- 修复迟到的 Bonjour 回调可能隐藏配对码的问题；保留原生线程启动前的取消请求。配对引擎增加 120 秒总时限，系统后台到期仍会提前结束配对。
- “复制诊断”增加最多 32 条本次启动内的配对进度，包含阶段耗时和地址族，不含配对码、IP 地址、设备标识、密钥或配对文件。下一次配对时清空，不上传。
- 在系统设置发起配对后，请返回 WrapPin 查看配对码，再回到设置输入；App 不发送配对码通知。

## 安装包

[下载 v1.0.23](https://github.com/suversal/WrapPin/releases/tag/v1.0.23)。两版均为支持 iOS/iPadOS 18.0+ 的未签名 IPA。

- Standard 标准版：适合 SideStore 等自签，配合 LocalDevVPN 等外部设备隧道。
- Tunnel 隧道版：内置设备隧道，主 App 和扩展都需要匹配的 Packet Tunnel 签名权限；免费账号请选择标准版。

沿用原签名身份覆盖升级同一版本类型即可；正常工作的配对无需移除。iOS 18–26 仍通过电脑生成并导入 RPPairing，本机配对码流程需要 iOS 27。

## 验证范围

原生测试覆盖身份更换与保存恢复、真实 IPv4/IPv6 回环接入、线程启动前取消。Swift 生产代码故障注入覆盖配对/保存期间重置、重试隔离、配对码显示顺序、诊断隐私、导入与重置交错、钥匙串旧读取迟到。现有离线回归、两版 Debug/Release 编译和安装包检查结果见[构建记录](../Releases/PairingReset-build75/receipt.json)。

当前环境没有复现反馈用户手机上的“不出配对码”。受影响设备、beta 系统和签名后安装仍待真机验收；本版处理了已确认的实现缺口，不代表已证明该故障的唯一原因。不会还原手机系统或清理其他 App 数据。
