# 1.0.23 Build 75 真机回测

沿用原签名身份覆盖安装相同版本类型。正常配对无需删除。免费账号使用 Standard 标准版，并保留外部设备隧道；Tunnel 需要主 App 与扩展的 Packet Tunnel 签名权限。

1. 先确认原来的定位仍可使用；正常启动不应更换已保存的配对身份。
2. 在受影响的 iOS 27 beta 手机上，移除配对，等待完成，再开始“配对本机”。不要恢复手机系统。
3. 在设置中选择与 WrapPin 配对后，切回 WrapPin 查看六位码，再返回设置输入；App 不发送配对码通知。
4. 若没有码，在本次启动内打开连接状态并复制诊断，区分没有 TCP 接入、握手拒绝和已生成配对码。不必发送配对文件或密钥。
5. 成功后重启 App，确认记录仍有效、可连接定位；再进行一次主动重新配对。
6. 分别验证取消后重试、配对中重置、替换/导入记录期间重置，不应恢复旧配对状态。
7. 验证停止定位、恢复真实位置和路线暂停/恢复。长时间后台与锁屏效果另行记录。

本机已完成 15 组离线检查、15 项 Rust 测试、双版 Debug/Release 编译及 IPA 校验；上述真实设备场景仍待验收，不能将回环/故障注入结果视为该手机故障已复现。
