# WrapPin 1.0.21 Build 70 本地测试候选

两个包均为未签名 IPA，最低系统为 iOS/iPadOS 18.0，包含 iPad 横竖屏布局。尚未公开发布。

| 安装包 | 设备隧道 | 系统版本 |
| --- | --- | --- |
| `WrapPin-Standard-1.0.21-build70-unsigned.ipa` | LocalDevVPN 等外部设备隧道 | iOS/iPadOS 18.0 起 |
| `WrapPin-Tunnel-1.0.21-build70-unsigned.ipa` | 内置；主 App 与扩展需带 Packet Tunnel 权限的签名配置 | iOS/iPadOS 18.0 起 |

不按系统版本另拆包。同一版本在 iOS 18–26 导入电脑生成的 RPPairing，在 iOS 27 使用开发者设置中的六位码本机配对。

## 安装与验收

1. 沿用当前安装方式签名、覆盖安装对应版本，无需主动重置配对。
2. iOS 18–26：在电脑 idevice_pair 中选择 Remote pairing，生成并验证后保存同一份 RPPairing，再导入 WrapPin。v1.1.0 的 Validate 在 Create 成功后才显示，确认 Works 后保存；不要使用 Lockdown / SideStore 的配对记录。
3. iOS 27：沿用“配对本机”及开发者设置中输入六位码的流程。
4. 保持开发者模式、Wi-Fi 与设备隧道就绪；先测固定位置、停止恢复，再测路线和后台。
5. iPad 检查双向横屏、竖屏、旋转后选点保留、设置和导入入口；宽窗口为左侧操作区和右侧地图，窄窗口为浮层布局。

详细配对操作见[电脑配对说明](../../Documentation/iOS26Pairing.zh-CN.md)。两个版本分别保存配对记录，切换版本后需要分别导入。

## 已检查与待验收

两版最低系统为 18.0 的 Debug 编译、Release Archive、11 项离线检查及 IPA 完整性、版本、架构、设备类型、方向、扩展与签名配置布局均通过。源码提交与 SHA-256 见[构建记录](receipt.json)。

iPad 界面曾在现有 iOS 26.3.1 运行时上通过横竖屏、选点保留、中文最大辅助字号与深色引导页检查，测试设备已清理。该界面检查发生在 iOS 18 API 兼容分支调整之前，未验证配对或定位。没有下载 iOS 18 模拟器运行时。

此前 Build 69 标准版在 iOS 26.5 上有首轮成功反馈。Build 70 的 iOS 18 真机、iPad 真机定位、隧道版与 iOS 27 本机配对等仍需验收。此包未新增 DDI 下载／挂载功能；定位服务不可用时应同时检查开发者镜像准备状态。现有引擎对部分配对校验错误仍统一提示“已保存的配对已失效”，应在“设置 → 连接检测 → 复制诊断”查看阶段，不能只凭这句话判定记录过期。
