# iOS 26 适配测试包：1.0.21 Build 69

这是本地候选包，尚未发布到 GitHub。标准版 iOS 26.5 已有首轮成功反馈，完整真机回归待完成。源码位于独立的 `codex/ios26-compat` 分支，基于正式 1.0.20；未混入 Build 67 配对诊断或 Build 68 去快捷指令实验，保留正式版功能。

## 安装与测试

1. 通过侧载工具或证书签名安装 `WrapPin-Standard-1.0.21-build69-unsigned.ipa`；已有安装时可覆盖安装。
2. 在电脑上用 [idevice_pair](https://github.com/jkcoxson/idevice_pair/releases/latest) 连接并信任这台 iPhone，选择 **Remote pairing（RPPairing）**。v1.1.0 中先点 Create，成功后点 Validate，显示 Works 后再保存同一份文件。
3. 把文件传到同一台 iPhone 的“文件”App。在 WrapPin 的“设备连接”页轻点“导入 RPPairing 文件”；也可以主动粘贴文件的 XML 内容。
4. 保持开发者模式、Wi-Fi 开启。打开 LocalDevVPN 并连接设备隧道，返回 WrapPin 开始固定定位，在苹果地图确认效果。
5. 停止并确认真实位置恢复，再测试路线、后台运行、重启后的再次连接。

导入成功表示文件校验和保存成功，真实隧道、开发者镜像（DDI）和定位服务仍需真机确认。此包未新增 DDI 下载或挂载。如果隧道已连通但定位服务不可用，需要进一步确认开发者资源准备状态。

## 两个版本的变化

- 最低系统为 iOS 26.0；iOS 26 首次配对通过电脑生成 RPPairing，iOS 27 保留六位码本机配对。
- 文件导入与主动粘贴共用校验：XML/binary plist、密钥配对和设备身份字段；能识别选错的 Lockdown 文件。
- 无效替换保留原来有效记录；活动会话中禁止更换配对文件。
- 标准版继续使用外部设备隧道；两个版本分别保存配对记录。

详细操作见 [iOS 26 电脑配对说明](../../Documentation/iOS26Pairing.zh-CN.md)。哈希、包大小和校验记录见 `receipt.json`。

## 2026-11-05 标准版真机反馈

用户先测标准版，设备系统为 iOS 26.5。最初在开始定位时报告 `pairVerification / idevice RemotePairing 103`。电脑 idevice_pair v1.1.0 中的 Remote pairing 显示 Validate → Works；在指引保存并导入同一轮新验证文件后，用户回复“这次好了”。

这记录了首轮成功反馈，不等于所有功能或整个 iOS 26 系列已验收。恢复真实位置、路线、后台、重启后重连、隧道版及其他系统版本仍待分别确认；此前失败是否由于新旧文件混用，尚无充分证据。
